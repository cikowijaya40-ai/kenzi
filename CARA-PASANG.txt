PATCH KENZI (gabungan): Mode Maintenance Produk + Optimasi Usage Vercel/Supabase + GitHub Sync dihapus
=====================================================================================================

1) Timpa semua file di patch ini ke project (struktur folder sama persis).

2) HAPUS 2 file/folder ini dari project (fitur GitHub sync sudah dibuang):
     src/lib/github.ts
     src/app/api/admin/github/            (seluruh folder)
   Env GITHUB_TOKEN / GITHUB_OWNER / GITHUB_REPOS / GITHUB_BRANCH tidak dipakai lagi, boleh dihapus dari Vercel.

3) Jalankan 2 file SQL ini SEKALI (urutan bebas) di Supabase -> SQL Editor. Aman dijalankan ulang:
     supabase/migrations/2026-11-product-maintenance.sql   (kolom maintenance produk)
     supabase/migrations/2026-11-usage-optimization.sql    (cron pembersihan DB + index webhook top-up)

4) Deploy ulang ke Vercel.

Catatan: sebelum SQL maintenance dijalankan, simpan produk tetap normal; hanya toggle maintenance yang
memunculkan peringatan dan belum tersimpan.
